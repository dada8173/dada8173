## 🔬 Current Research｜目前研究

### MGHE — Moment-Guided Hypergraph Enhancement for Open-World Retail Object Detection

I am currently working on **open-world object detection in retail environments**, with a focus on improving the representation and detection of unknown objects.

My current work, **MGHE**, extends YOLO-UniOW with multi-scale feature aggregation and moment-guided adaptive hypergraph enhancement to improve unknown-object detection in complex retail scenes.

目前研究聚焦於**零售場景中的開放世界物件偵測（Open-World Object Detection, OWOD）**，探討模型如何在既有已知類別之外，更有效地辨識潛在未知物件。

目前進行的 **MGHE** 研究以 YOLO-UniOW 為基礎，透過多尺度特徵聚合與 Moment-Guided Adaptive Hypergraph Enhancement，強化複雜零售場景中的未知物件特徵表達。
